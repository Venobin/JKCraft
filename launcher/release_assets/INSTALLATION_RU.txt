JKCRAFT 0.1.2 ALPHA — УСТАНОВКА
================================

Это первая тестовая версия клиента для Windows. Мод не содержит оригинальные
ресурсы Jedi Academy и Minecraft. Используйте его только со своими копиями игр.
Мультиплеер пока не готов; свободно введённый ник действует локально.
Автор JKCraft — Venobin. При разработке использовался Codex (OpenAI) как
инструмент ИИ; OpenAI не является автором или издателем проекта.
JKCraft основан на SkyCraft от chasmlol (https://github.com/chasmlol/SkyCraft)
и использует изменённый OpenJK (https://github.com/JACoders/OpenJK).

1. Распакуйте всю папку JKCraft-0.1.2-alpha. Не переносите отдельно один JAR.
2. Скопируйте из своей чистой Jedi Academy файлы assets0.pk3, assets1.pk3,
   assets2.pk3 и assets3.pk3 в:

   GameResources\JediAcademy\GameData\base\

   Лаунчер всегда использует эту папку внутри JKCraft. Выбор другой папки
   отключён.
3. Запустите JKCraft.cmd. Он использует Java 25 из папки Runtime, так что
   устанавливать Java отдельно не требуется. Можно открыть
   JKCraft-Launcher.jar напрямую, если в Windows настроена Java 17 или новее.
4. Впишите ник (по умолчанию Jaden) и нажмите «НАЧАТЬ ИГРУ».
   Кнопка RUS/EN меняет язык лаунчера и запоминает выбор.
5. При первом запуске для Minecraft 26.3, Fabric и библиотек понадобится
   подключение к интернету: клиент подготовит зависимости в папке
   RuntimeCache. Этот процесс может занять несколько минут и много места.
   В дальнейшем запуск использует локальный кэш. Никакая учётная запись не
   вводится в этом локальном тестовом режиме. Лаунчер показывает текущий этап
   и доступное имя скачиваемого файла. Полоса движется без точного процента,
   пока сервер загрузки не сообщает общий объём работы.
6. Игра отображается в окне OpenJK. Во время игры кнопка лаунчера становится
   красной «ЗАКРЫТЬ». Она завершает игру; закрытие окна лаунчера также
   завершает запущенные им OpenJK и Minecraft.

Папка GameResources\Minecraft\GameData хранит настройки, миры, ресурспаки и
прочие данные Minecraft. Сохраняйте её при обновлении клиента. Файлы
сохранений Jedi Academy находятся в UserData\OpenJK\saves. Не удаляйте их.

Если возникла ошибка, проверьте UserData\launcher.log. Убедитесь, что
GameData Jedi Academy содержит все четыре assets*.pk3, а в системе есть
доступ к интернету для первого запуска. Локальный режим не подтверждает
право владения Minecraft и не даёт доступа к официальным сетевым серверам
под произвольным ником. Для дальнейшего распространения не добавляйте игровые
ресурсы, чужие сохранения или свои учётные данные.

Исходники изменённого OpenJK находятся в проекте JKCraft, но не входят в
клиентский ZIP. Лицензии находятся
в папке licenses и внутри Runtime\Java25; лицензия SkyCraft сохранена как
licenses\SkyCraft-LICENSE.txt. Новые части JKCraft распространяются по MIT
(licenses\JKCraft-LICENSE.txt), изменённый OpenJK — по GPL-2.0
(licenses\OpenJK-LICENSE.txt).
