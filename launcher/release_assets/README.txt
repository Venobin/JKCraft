JKCraft 0.1.3 alpha
===================

Created by Venobin with AI-assisted development using Codex (OpenAI).
This does not imply OpenAI authorship or endorsement.

Start with JKCraft.cmd. Read INSTALLATION_RU.txt or INSTALLATION_EN.txt.
This package contains no original Jedi Academy or Minecraft game assets.
The RUS/EN button changes the launcher language. Default local name: Jaden.
Game resource paths are fixed inside this folder; see the installation guide.

JKCraft is based on SkyCraft by chasmlol:
https://github.com/chasmlol/SkyCraft
It also uses modified OpenJK: https://github.com/JACoders/OpenJK
Original copyright notices and license texts are preserved in the JKCraft
source project and licenses folder. New JKCraft components use MIT; modified
OpenJK retains GPL-2.0.
This is an experimental fan project, not an official game client.

For support, attach UserData\launcher.log without personal information.
